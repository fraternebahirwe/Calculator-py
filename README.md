# 🧮 Calculator-py

> A lightweight, command-line interface (CLI) calculator built with Python that performs basic arithmetic operations with built-in input validation and error handling.

![Python](https://img.shields.io/badge/Python-3.x-blue?style=for-the-badge&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

---

## ✨ Features

- **Basic Operations:** Supports addition, subtraction, multiplication, and division.
- **Command-Line Interface:** Execute calculations directly from your terminal using positional arguments.
- **Robust Error Handling:**
  - Safely handles division by zero.
  - Validates argument counts and non-numeric inputs gracefully.
  - Automatically converts integer and floating-point inputs.

---

## 🛠️ Built With

- **Language:** Python 3
- **Modules:** `sys` (built-in standard library)
